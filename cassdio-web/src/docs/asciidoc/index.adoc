== Documentation Policy

API 문서는 Spring REST Docs 테스트가 생성한 snippets만 조립한다.
새 API는 정상 응답 테스트와 필요한 validation/auth 실패 테스트를 함께 추가해야 문서에 포함된다.

== Common Response

=== Success

[source,json]
----
{
  "code": "200",
  "message": "Success",
  "data": {},
  "timestamp": 1234567890
}
----

=== Error

[source,json]
----
{
  "code": "E001",
  "message": "Invalid request",
  "errors": [],
  "traceId": "trace-id",
  "timestamp": 1234567890
}
----
